# বাজার দর (BazarDor)

দৈনন্দিন নিত্যপ্রয়োজনীয় পণ্যের বাজার দর পর্যবেক্ষণ ও বিশ্লেষণের একটি আধুনিক প্ল্যাটফর্ম।

## 🚀 প্রযুক্তিসমূহ (Technologies Used)

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, DaisyUI
- **Language:** TypeScript
- **Authentication:** BetterAuth (Email/Password, Google, GitHub)
- **Icons & Visuals:** Lucide Icons, Custom Vector Illustrations
- **Notifications:** React Hot Toast

## ✨ মূল ফিচারসমূহ (Key Features)

1. **রিয়েল-টাইম প্রাইস ট্র্যাকার (Ticker Bar):** সাইটের শীর্ষে চলমান টিকারে প্রতিদিনের প্রয়োজনীয় পণ্যের দর এবং এর শতকরা হ্রাস/বৃদ্ধি একসাথে দেখা যায়।
2. **ক্যাটাগরিভিত্তিক সর্টিং (Bengali Numeral Sorting):** চাল, ডাল, তেল, সবজি ইত্যাদি ক্যাটাগরিতে পণ্যগুলোকে দামের ঊর্ধ্বক্রম ও নিম্নক্রম অনুযায়ী সঠিক বাংলা সংখ্যা রূপান্তরের মাধ্যমে ফিল্টার করার সুবিধা।
3. **বাজারভিত্তিক দর বিশ্লেষণ:** প্রতিটি পণ্যের জন্য দৈনিক সর্বনিম্ন, সর্বোচ্চ এবং গড় দর দেখার পাশাপাশি বিভিন্ন বাজারের পণ্যের দামের বিস্তারিত ওভারভিউ।
4. **সুরক্ষিত অথেন্টিকেশন সিস্টেম:** BetterAuth এর মাধ্যমে ইমেইল, পাসওয়ার্ড এবং সোশ্যাল লগইন (Google/GitHub) সার্ভিসসহ নিরাপদ লগইন ও প্রফাইল আপডেট অপশন।
5. **রেসপন্সিভ এবং অ্যাক্সেসিবল ডিজাইন:** ডেস্কটপ, ট্যাবলেট এবং মোবাইল ডিসপ্লের সাথে সামঞ্জস্যপূর্ণ আধুনিক ক্লিন UI ইন্টারফেস।
